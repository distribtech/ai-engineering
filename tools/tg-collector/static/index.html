3. Період

Кілька каналів качаються по черзі: по сторінці (~20 постів) з кожного, фото — після текстів. Шкала — від найстарішого поста вибраних каналів до сьогодні. Якщо канал молодший за період, береться вся його історія. Дати — за UTC.
